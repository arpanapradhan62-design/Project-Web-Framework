Web Frameworks Assignment
This repository contains the **Web Frameworks assignment** including a Django application, a Streamlit app, and a Data Engineering project using the Titanic dataset.
Folder Structure

1. Django Web Application
Steps to run:
1. Open terminal (Git Bash or Command Prompt)  
2. Navigate to the Django project folder:
bash- cd django_app
bash-python manage.py runserver
http://127.0.0.1:8000/
Django application running.
Screenshots of the application are in the screenshots folder.

2.Streamlit Application
Steps to run:
Open terminal
Navigate to the Streamlit app folder:
bash-cd streamlit_app
bash- python -m streamlit run app.py
A browser window will open with the Streamlit interface.
Screenshots of the app are also in the screenshots folder.

3.Titanic Data Engineering

Contents:
Database: titanic.db
Notebook or Python file: titanic_analysis.ipynb or .py

Steps to run:
Open your notebook in Jupyter Notebook.
The code reads the Titanic dataset, performs basic data cleaning (filling missing values for Age and Embarked) and explores the dataset.
You can also use your local SQLite database to query the data.

4. Screenshots

All screenshots of the running Django and Streamlit applications are in the screenshots folder for reference.

5. Notes
Ensure you have Python and required packages installed:
pip install django pandas streamlit sqlite3
Run Django and Streamlit in separate terminals if needed.
The repository is organized so all files for grading are visible and accessible.
